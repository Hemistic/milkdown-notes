# 侧栏弹性布局与 AI / Diff 验收

日期：2026-10-24。版本：Milkdown / Crepe 7.22.3。本地 Chromium 浏览器实际操作，使用本项目的编辑器模块。

## 结果

- AI / diff 浏览器回归：18/18 通过。
- Node 测试：8/8 通过，包含 OpenAI、Anthropic provider 协议测试及适配锚点检查。
- TypeScript 检查、构建通过。
- 七种 AI 操作实际点击执行：改写、学术润色、精简、扩写、修正语法、翻译为中文、翻译为英文。确认各自传递正确的 instruction、selection 和 document；返回内容使用固定样本，不代表真实语言模型质量。
- 自定义要求提交、Ctrl+Enter 接受全部、逐项接受与放弃、Esc 关闭菜单和停止生成均实际操作。

## 宽度与高度

主应用分别验证 240、280、360、480、640、900、1280 CSS px 宽度。900 px 宽度时另使用 400 px 高度，其他档位使用 720 px。各档 `scrollWidth === clientWidth`，菜单右边界、下边界在视口内。工具支持的最小视口为 240 px，未把请求的 220 px 误记为通过。

窄窗口中，子菜单在主菜单内展开；菜单过高时内部滚动。280 × 640 窗口实际滚动并切换中英文，确认底部操作可达。宽窗口恢复悬停展开子菜单。

在 480 px 窗口内嵌入 240 px 编辑区域，AI 菜单和斜杠菜单均在编辑器左右边界内：宿主约 120.57–359.43 px，菜单约 128.57–351.43 px。AI 菜单不被滚动容器裁切；选文工具栏换行后仍保留全部十个入口。实际通过斜杠菜单插入表格，宽表格继续内部横向滚动。

保持 diff 活跃时连续调整 240、360、480、800 px 窗口，操作栏跟随宿主定位、换行，全部按钮保留；不随窗口中心跑出侧栏。预留正文底部空间，避免短文最后几段被操作栏遮挡。

## AI 回归范围

| 范围 | 检查结果 |
| --- | --- |
| 上下文与保存 | 选区和全文完整；流式草稿、未接受 diff 不触发保存 |
| 接受与放弃 | 全部接受、全部放弃、逐项混合决策正确；接受后可撤销、重做 |
| 重试 | 沿用原始选区和要求；部分接受后禁止不安全重试 |
| 停止 | 取消并回退、停止并保留部分输出均有效 |
| 错误 | 首字前失败、流中失败、构造上下文失败均回退并恢复编辑；重试清除旧错误 |
| 边界 | 空返回不删除选区；相同返回不破坏原文；光标空选区插入有效；拒绝重复请求 |
| Markdown | 分片经过表格、代码、公式、加粗后仍正确解析与序列化 |
| 生命周期 | 生成中销毁会 abort；晚到回调不访问已销毁上下文；重新挂载有效；只读或无 provider 不显示 AI |
| 异步错误 | 最终 18 项回归无未处理异常 |
| 内置 provider | OpenAI / Anthropic 均通过分割 UTF-8 SSE、中文内容、上下文、HTTP 503 和 AbortSignal 测试；fetch 完全使用本地桩，无远程请求 |

Milkdown 原生 Esc 在生成时使用 `keep: true`，即停止并保留已生成部分。界面提示改成“Esc 停止并保留”，没有把它误称为回退原文。需要回退时可撤销；API 的 `abortAICmd({keep:false})` 在回归中单独验证。

## 本轮修复

1. 只读实例没有安装 AI 功能，销毁时不再误调用 AbortAI。
2. Crepe 的异步 provider 在销毁后进入 finally，原本访问已经移除的 aiSession。构建适配增加上下文存在检查，并用版本和源代码锚点校验防止依赖更新后静默失效。
3. AI 菜单改为 fixed 定位并限制在宿主与视口边界内，避免被侧栏滚动容器裁切。
4. diff 操作栏随宿主宽度、滚动位置变化；窄宽度自动换行，短文预留操作栏空间。
5. 生成／diff 审阅时隐藏普通选文工具栏；新请求清理旧失败提示。
6. 主菜单、斜杠菜单、引用菜单、代码工具、公式滚动和流式提示增加宽度约束；ResizeObserver 在销毁时清理。

## 重现与边界

运行 `npm run build`、`npm start`，打开 `/example/ai.html`，点击“运行完整回归”。页面也提供正常流式、慢速、失败、空返回场景，以及侧栏宽度选择，便于继续人工验收。测试页不读写本地笔记文件。

没有配置真实模型服务或凭证，因此本轮完成的是编辑器交互与协议验收，不包含真实服务鉴权、限流、计费、生成质量或网络端到端测试。也未声称覆盖所有浏览器、触摸设备、IME、任意极端宽度或任意 Markdown 文档组合。

能力范围参照 [Milkdown Crepe 官方 API](https://milkdown.dev/docs/api/crepe)，行为细节以安装版本 7.22.3 的源代码与实际测试为准。

# 2026-10-29 源码清理与接入验收

审计范围：编辑器、侧栏、本地文件服务、构建适配、测试、样式和直接依赖。用户数据 `.data` 和来源工程 `D:/Project/pdf-ai` 未修改。

## 删除与简化

- 删除未使用的静态代码快照生成/高亮/复制实现、`wb-code-*` 样式，以及只为该快照写 DOM 属性的上游构建补丁。
- 删除未使用的 Wiki 目标解析器、缓存和 `remark-parse` 直接依赖；`unified` 只保留实际使用的类型依赖。
- 删除未调用的 SVG 重编号入口、Markdown 大纲解析器、excerpt 分支、内部 setReadOnly 方法、assets 兼容参数、menuToolbar 配置和未使用 imports。
- 删除 Artifact 专用“在 ArtInFact 中打开”分支、重复文件菜单、废弃 onExportSnapshot 回调，以及对应专用样式。保留正在使用的原 SVG 和底栏尺寸。
- 删除未引用的图标条目、遗留标题输入框样式、重复编辑器配置。
- 移除动态注入备用 CSS，所需正文/公式样式归入正式 stylesheet；删除重复绑定 WeakMap、额外 Mermaid 自定义长度/边数限制，使用上游默认行为。
- 将重复的临时文件写入逻辑合为 atomicWrite；自动保存使用一个共享写入任务，删除吞掉保存失败的旧队列链。
- TypeScript 启用 noUnusedLocals/noUnusedParameters；源码使用 Prettier 统一格式，提供 format / format:check。

HTML 净化、文件路径和本地 Origin 校验、原子保存、AI 草稿隔离、取消清理、上游补丁锚点检查仍有实际调用和失败场景，予以保留。它们分别防止执行正文脚本、越界访问文件、丢稿及错误修改上游代码，不属于废代码。

## 接口与修复

- 新增 `@local/milkdown-sidebar`，本地应用改为消费同一可挂载侧栏。
- `NoteFiles` 统一列表、读取、保存、重命名、图片上传/解析；`createHttpFiles` 是内置 HTTP 实现。
- `NoteEditor.ai` 提供 run/abort/accept/reject/getState；AIProvider 和上下文类型公开，可选 provider 通过独立 providers 入口导入。
- 导出可交给宿主保存或原生 PDF 转换；去掉 `/app.css`、`/editor/style.css`、`/assets` 的固定导出路径。
- 主题、控件 ID、样式和布局改为实例范围；标题 ID 也按编辑器区分，导出时还原便携锚点。宽度适配依据侧栏容器。
- 修复慢写和读取下一篇期间输入导致的丢稿窗口；立即 setMarkdown + flush 正确保存。保存失败阻止切换/卸载并允许重试。
- 卸载清理菜单监听器、ResizeObserver、模式遮罩、React 根和编辑器浮层。

## 第二轮简化与全面回归

本轮以删掉重复防御和降低阅读成本为主：

- 删除挂载 WeakSet、逐方法 assertLive，以及表格、选文工具栏和侧栏重复的 disposed 标记；异步回调停止与销毁资源清理保留在生命周期入口。
- 底栏内部参数改为必传，删除已经明确存在的回调判空和默认值；两个始终一致的就绪参数合成 ready。
- 侧栏事件统一由 perform 排队并报告错误，删除重复 Promise 包装；导入选择立即复位，失败后可以重新选择同一文件。
- 引用导航改成直接 async/await；修复反向链接回调失败产生未处理拒绝的问题，显示具体失败原因。
- 上游构建适配合并为一个 patchFile 替换函数；删除重复版本检查循环和各处重复的文本检查实现。
- 编辑器宿主恢复、撤销分组集中到各自函数；删除无用别名和翻译条目。
- 修复上游浮层异步定位在销毁后读取光标 DOM 的时序错误：计算开始前获取坐标快照，不新增销毁状态判空。回归同时检查控制台错误。

生命周期契约明确由调用方遵守：每个容器只使用一个实例，销毁后停止调用旧实例；不为这些误用逐方法堆叠检查。真实外部输入与文件写入的处理仍位于对应边界。
